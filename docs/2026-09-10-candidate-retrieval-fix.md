# C-2419 候选检索修复

问题：明确补充两张订购表后，检索器将明确表名当作唯一候选，排除了已发布的号码来源表。字段详情工具也无法补查目录外对象。

本次范围：明确表名优先保留，剩余候选名额按已有相关性排序补齐、去重。默认仍为八张；明确引用超出预算时全部保留。没有改动业务口径、关联校验或自动扩大表族的逻辑。自然语言的“仅限某些表”仍需规划器遵守，本次不新增关键词解析器。

验证：补充针对性回归用例，先复现旧逻辑漏掉相关表；再检查候选上限、明确表保留及原有字段详情行为。不调用模型，不写入会话数据库。

后续：为大模型提供按需元数据搜索工具，并使扩展后的候选目录与校验上下文保持一致。本次初始召回修复不等于已保证SQL正确。
