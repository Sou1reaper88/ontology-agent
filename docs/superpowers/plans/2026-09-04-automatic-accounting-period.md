# 自动账期实施计划

**目标：** `_D` / `_M` 表无需配置，按实际分区字段自动使用 T−2 / 上一个完整自然月；需求明确账期优先。

**架构：** 集中定义表名约定，管理端派生只读策略，新版本构建固化派生规则；运行时加载历史版本时派生有效策略，不修改历史 RDF 或摘要。既有非标准表的旧策略保留兼容，没有旧策略的非标准表不推断粒度。

**边界：** 表名和字段名大小写不敏感；只使用真实、启用的分区字段，缺失/歧义报错。已导入但未发布的元数据仍不能用于取数。无数据库执行、无外部模型评测、无自动发布。
