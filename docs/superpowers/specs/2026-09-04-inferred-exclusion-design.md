# 元数据候选计划的排除语义

用户批准：修复取数排除逻辑，不强制LEFT JOIN或NOT EXISTS，其余范围保持不变。

计划显式区分inner（匹配）、left（保留左侧）和anti（排除右侧匹配），anti_strategy支持left_join及not_exists。过滤scope区分match与where，避免右表筛选移入WHERE导致左连接退化。反连接右侧的业务条件与分区条件必须进入匹配范围；普通left可以显式在WHERE检查右键IS NULL。

anti右侧为独立叶节点，不提供结果字段、不继续关联其他对象。连接方向不可反转；无法完整编译的图或额外关联条件应报错。仅支持现有单等值关联键，不扩展任意SQL表达式。

blocking_issues记录模型识别到的核心未实现语义，校验器据此停止生成。普通unresolved_items继续用于待确认假设，不以自然语言关键词硬判意图。该机制依赖模型正确分类，不承诺自动证明任意需求语义完全正确。

验证包括合成内存数据上的两种反连接结果、双表排除、重复记录、空键、过期分区、普通左连接及方向/作用域拒绝。真实用例仅调用模型，不执行业务SQL；参考SQL与元数据不进入Git。
