# 模型编写 SQL，Python 校验

用户已确认直接切换，不使用影子运行。保留当前自然会话工具调度；生成工具内部让模型检索本体、补查字段、编写完整 Hive 脚本并调用静态校验。Python 不再要求模型先输出关系代数计划，也不重新渲染模型 SQL。

复用候选目录、字段查询工具、sqlglot 和既有程序展示合同。模型可以根据真实字段推断未登记的关联及业务口径；NULL 在沉默用户场景可以表示无使用，但不自动扩展到其他字段。假设和待确认项随结果提供。

脚本仅输出，不执行。每个物化步骤是一对 DROP TABLE IF EXISTS / CREATE TABLE AS SELECT，目标限本次临时表命名空间，不生成末尾清理。校验来源、字段、步骤依赖和基础扫描的有限分区条件。禁用 CTE 由会话模型理解后传给工具，并通过 AST 检查；没有禁止时允许 CTE。直接调用生成器也要求作者声明其识别的 CTE 约束。

允许用户明确指定的外部表，但其字段无法按本体验证，须记录该边界。静态校验不能证明业务口径正确；模型也可能遗漏自然语言要求，真实效果仍由前台验收及授权测试确认。

工具查询有界；校验失败最多一次定向修复，提供方失败不重试。旧编译器暂留作独立兼容模块，不是默认输出或失败兜底。无新依赖、无全量测试、无未经授权的付费模型调用。
