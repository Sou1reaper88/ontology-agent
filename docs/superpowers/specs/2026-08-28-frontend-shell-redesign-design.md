# 前端全局外壳首期重构设计

## 目标

将现有默认 Ant Design 风格升级为 A 方案“理性研究台”，先建立可复用的产品视觉基础，并让用户能在登录页和所有登录后页面立即看到明显变化。本期不重构智能取数、本体管理、评测和管理页面的内部信息架构。

## 范围

本期仅包含：

- 全局设计令牌、字体、背景、色彩、间距、圆角、阴影与交互状态；
- Ant Design 主题配置与少量全局样式；
- 登录页；
- 登录后的顶部导航和页面内容外壳；
- 当前路由导航高亮、键盘焦点、窄屏导航和基础响应式行为；
- 统一按钮、输入框、表格、卡片、空状态和加载状态的基础观感，但不改页面业务逻辑。

本期不包含：

- Chat 页面内部布局拆分或交互变更；
- 本体工作台内部布局、编辑器和抽屉重构；
- 后端接口、权限模型、路由结构和数据模型变更；
- 新增深色主题、动效框架或图标库。

## 视觉语言

- 主背景使用偏暖的浅灰白，正文使用深石墨色，避免纯白与纯黑的大面积对撞。
- 仅使用低饱和青绿色作为品牌强调色；危险、警告和成功色只承担语义状态，不作为装饰色。
- 使用适合中文数据工具的系统字体栈，不引入远程字体依赖；SQL 和数字使用等宽字体或等宽数字。
- 页面通过分隔线、留白和背景层级组织信息，减少默认的“白卡片 + 边框 + 阴影”堆叠。
- 交互状态包含悬停、按下、键盘焦点、禁用和加载反馈，并尊重减少动态效果的系统设置。

## 页面外壳

登录后的页面由三个稳定区域组成：

1. 跳转到主要内容的无障碍入口；
2. 顶部产品导航；
3. 带最大宽度和响应式内边距的主要内容区域。

顶部导航显示产品标识、核心模块入口和用户操作。导航激活项根据当前路由计算，不再固定高亮“智能取数”。退出操作使用语义化按钮。桌面端展示完整入口；窄屏端将模块入口收纳为可操作菜单，主要内容保持可访问。

页面外壳只负责布局、导航和全局状态，不持有业务页面数据，避免后续重构 Chat 或本体工作台时互相耦合。

## 登录页

登录页采用左右非对称布局：品牌与产品能力说明作为视觉锚点，登录表单保持紧凑明确。窄屏时折叠为单列并优先展示表单。

登录行为、字段和接口保持不变。移除会泄露默认账号习惯的占位文本，补充字段标签、错误提示区域、提交中状态和键盘操作体验，不添加虚构数据看板或装饰性 AI 渐变。

## 组件与代码边界

- 全局设计令牌和基础元素样式放入独立样式文件；
- Ant Design 的主题映射集中在应用入口附近；
- 页面外壳组件只处理导航、路由高亮、退出和响应式结构；
- 登录页保留现有认证流程，只替换布局与表现层；
- 不在本期批量重写各业务页面的内联样式，避免范围失控。

## 状态与兼容性

- 路由切换后激活导航必须同步更新；
- 登录失败沿用后端错误信息，并以页面内错误状态展示；
- 提交期间按钮不可重复触发，并保持明确的加载反馈；
- 在常见桌面宽度和手机宽度下不得出现主要内容横向溢出；
- 现有路由、接口调用和权限判断保持兼容。

## 验收标准

- 登录页、顶部导航和页面背景与当前版本相比有明显且统一的视觉变化；
- 所有登录后页面共享同一套色彩、字体和内容外壳；
- 当前页面导航高亮正确，退出按钮可通过键盘访问；
- 登录和退出流程保持可用；
- Chat、本体管理、评测和管理页面的既有业务功能不因本期改造而改变；
- 完成后启动本地服务，由用户先进行视觉验收，再决定第二块改造内容。
